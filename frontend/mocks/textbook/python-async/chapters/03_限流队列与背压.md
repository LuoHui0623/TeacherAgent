## 限流、队列与背压

异步系统最危险的状态通常不是“没有任务”，而是任务无限堆积。并发数量、队列长度和超时时间共同决定系统能否在压力下恢复。

### Semaphore 控制同时进行的工作

```python
import asyncio
from collections.abc import Iterable

async def bounded_map(values: Iterable[int], limit: int) -> list[int]:
    semaphore = asyncio.Semaphore(limit)

    async def one(value: int) -> int:
        async with semaphore:
            await asyncio.sleep(0.01)
            return value * value

    return await asyncio.gather(*(one(value) for value in values))
```

### Queue 连接生产者和消费者

`asyncio.Queue` 让生产者在容量用尽时等待，从而把下游压力反馈给上游。生产者调用 `put`，消费者调用 `get`，任务完成后必须调用 `task_done`。

$$
\text{吞吐量} \leq \min(\text{生产能力},\ \text{消费能力})
$$

队列不是越大越好。队列过大会隐藏延迟、增加内存占用，也会让失败发生得更晚。应结合请求超时和监控指标设置容量。
