## 可测试的异步服务

异步服务的测试重点不是把每个 `await` 都模拟一遍，而是验证边界行为：超时是否生效、取消是否清理、重试是否有上限、并发是否受到约束。

### 把 I/O 依赖注入服务

```python caption="将网络客户端作为协议传入"
import asyncio
from collections.abc import Awaitable, Callable

Fetcher = Callable[[str], Awaitable[str]]

async def fetch_with_timeout(fetcher: Fetcher, url: str) -> str:
    return await asyncio.wait_for(fetcher(url), timeout=2.0)
```

上面的服务只依赖一个异步可调用对象，因此测试可以传入一个确定性的 fake，而不必启动真实网络服务。

### 超时与重试的边界

重试只能处理暂时性故障，并且必须有次数、退避和总截止时间。对不可重试的参数错误继续重试，只会放大故障。

:::info{title="实践任务"}
实现一个带并发上限的 URL 批量抓取器：支持每个 URL 的超时、最多两次重试，并在任意任务失败时取消剩余任务。
:::

完成后检查三件事：任务是否都能被回收，取消是否能关闭资源，以及测试是否不依赖真实时间和网络。
