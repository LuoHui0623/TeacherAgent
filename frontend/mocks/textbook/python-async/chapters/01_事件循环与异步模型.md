## 异步模型与事件循环

异步编程的核心不是同时执行很多行代码，而是在任务等待 I/O 时，把执行权交还给事件循环。

一个 coroutine 描述可暂停的工作，Task 负责把 coroutine 交给事件循环调度。事件循环不断取出已经可以继续运行的任务，让等待中的程序保持流动。

### coroutine、Task 与 Future

| 对象 | 作用 | 常见来源 |
| :--- | :--- | :--- |
| coroutine | 描述可暂停的异步计算 | 调用 `async def` 函数 |
| Task | 为 coroutine 提供调度和生命周期 | `asyncio.create_task` |
| Future | 表示稍后会得到的结果 | 底层协议或第三方库 |

:::tip{title="先找等待点"}
分析异步代码时，先标出网络、磁盘、队列和锁等等待点，再判断并发是否真的能带来收益。
:::

```python caption="让两个 I/O 任务交错运行"
import asyncio

async def fetch(label: str, delay: float) -> str:
    await asyncio.sleep(delay)
    return f"{label} done"

async def main() -> None:
    first, second = await asyncio.gather(
        fetch("first", 0.2),
        fetch("second", 0.1),
    )
    print(first, second)

asyncio.run(main())
```

关键观察是：两个任务的总耗时接近较长的等待时间，而不是两个等待时间之和。
