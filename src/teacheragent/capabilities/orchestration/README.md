# 编排（orchestration）

## 职责

把各原子能力装配成可执行的预设 workflow（LangGraph），负责运行期控制流：并行展开、人工审批节点、失败回流与局部重跑。

## 输入 → 输出

| 输入 | 输出 | 说明 |
|---|---|---|
| 能力集合 + `WorkflowDefinition` | 可执行 workflow（`Run`） | 预设图，由本能力装配 |

## 边界

- 不实现原子能力的内部逻辑，只做装配与控制流。
- 原子能力不得反向依赖编排层。

## 提示词

- 无。编排是结构化装配，不依赖自然语言提示词。
